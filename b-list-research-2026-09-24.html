Methodology and data notes

Pipeline, rubric, data caveats and sources

Pipeline: TradingView Desktop (CDP) → dedicated "B List Research" layout → up to 500 bars per timeframe per symbol (W / D / 240 / 60 / 15, regular sessions) → indicators computed locally: EMA 10/21/50/200, RSI-14 (Wilder), MACD 12/26/9, ATR-14 (Wilder), 20-bar relative volume, fractal (2-2) swing pivots, 252-day high/low distances, relative strength vs SPY as return differentials. Trend matrix rubric per cell, ±1 for each of six inputs: close vs EMA21, close vs EMA50, EMA21/EMA50 stack, EMA50 five-bar slope, RSI zone (≥55 = +1, ≤45 = −1, else 0) and MACD histogram sign — score ≥+4 Up, ≤−4 Down, else Chop; cells lacking an EMA21 or EMA50 return "—".
